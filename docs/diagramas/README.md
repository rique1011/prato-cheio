# Diagramas do Projeto Prato Cheio

## Objetivo

Esta documentação reúne os diagramas utilizados para analisar o funcionamento do sistema Prato Cheio, comparar os modelos iniciais com as versões revisadas e registrar as decisões tomadas durante a atividade.

## Diagramas escolhidos

### 1. Diagrama de estados UML

Representa os estados possíveis de uma doação e as transições entre eles durante o fluxo do sistema.

O diagrama deve ser comparado com a implementação para verificar se os estados e as transições correspondem às regras reais do projeto.

### 2. Diagrama de sequência UML

Representa a interação entre os participantes e os componentes do sistema durante uma operação, como a aceitação de uma doação.

O diagrama deve mostrar uma sequência coerente com as chamadas e respostas implementadas no projeto.

## Ferramentas de inteligência artificial

Foram utilizadas ferramentas de IA como apoio à
elaboração dos diagramas.

- Diagrama de Estados: ChatGPT.
- Diagrama de Sequência: Claude Opus 5.5

As versões iniciais foram preservadas para permitir
a comparação com as versões revisadas.
